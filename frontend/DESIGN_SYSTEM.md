# 三端前端设计实现说明

更新日期：2026-10-22。实现依据为 `design/frontend-handoff/manifest.json` 中选定的三端 PNG、路由映射，以及根目录《前端开发规范.md》。历史三张参考图和旧截图不再作为本轮视觉基准。

## 主题与布局

| 项目 | 当前代码基线 |
| --- | --- |
| 字体 | Microsoft YaHei / PingFang SC / Arial / sans-serif；使用本机系统字体 |
| 基础文字 / 画布 | `#253750` / `#f3f6fa` |
| 默认主色 / 侧栏 | `#287fe5` / `#153b68` |
| 馆员主色 / 文字 / 画布 | `#0061ff` / `#101344` / `#eff8ff` |
| 成功 / 提醒 / 风险 | `#27ad8a` / `#dc9b36` / `#e45b61`，同时保留文字说明 |
| 侧栏 / 顶栏 | 常规侧栏 274px，较窄桌面 242px；顶栏 76px；内容独立滚动 |
| 读者首页 | 横幅基准高 333px，搜索与三列馆藏卡片按参考图排布 |
| 读者记录 | 大字号、封面和状态标签；不沿用旧版 40px 紧凑行 |
| 馆员编目 | 分类侧栏加封面卡片，保留筛选、分页、上下架、编辑和副本入口 |
| 后台业务 | 独立借出/归还核对区、统计图、管理表格和 Element Plus 弹窗 |

入口为读者 `127.0.0.1:5173`、馆员 `127.0.0.2:5174`、管理员 `127.0.0.3:5175`。三种主机地址保持 Cookie 隔离。登录页使用各自定稿的背景和布局。

样式加载顺序为 `main.css` → `reader.css` → `staff.css`。角色差异由 `shell-reader`、`shell-librarian`、`shell-admin` 限定。桌面最低布局宽度 1150px；验收目标为 1366×768、1920×1080，Chrome 缩放 100%。这些目标仍需浏览器实测，不能仅由媒体查询证明通过。

## 素材与组件

`frontend/public/design/` 保存 10 张独立装饰素材。来源、裁剪位置、补全提示词和 SHA-256 见 `design/asset-manifest.json`。读者/馆员登录背景、管理员摄影背景及横幅已去除 UI 文字并补全遮挡区域；Logo、侧栏装饰和异常状态插画按参考图提取。

常规输入、按钮、分页、表格、表单、标签、确认弹窗采用 Element Plus；图标使用现有图标库。页面文字和交互为实际 DOM，未用整张设计图覆盖页面。真实书目封面、用户名、公告、库存与统计来自 API。

## 页面与业务

已替换三端外壳、登录、读者首页/目录/详情/借阅/预约/资料/密码/公告/注册/异常页，以及馆员和管理员的工作台、编目、副本、分类、借出、归还、借阅、预约、公告、统计、账号、审计页面。

保留集中 API、Session、CSRF、门户校验、权限路由、字符串 ID 与写操作幂等键。公开公告显式查询 `PUBLISHED`。借还、预约、续借仍以后端状态与允许操作为准；冲突后重新读取数据。图表使用真实统计并提供摘要。

## 验证边界

代码检查和隔离 MySQL 的 35 项真实 API 验证已通过；详见 `design/implementation-checkpoints.md` 与 `design/api-verification-result.json`。用户正在使用电脑，本轮按其要求先完成代码和接口验证。Chrome 截图对照、色差微调与人工浏览器端到端走查尚未完成，当前不声明 1:1 视觉验收通过。完整状态见根目录 `design-qa.md`。
# 2026-10-22 桌面密度修订

用户要求所有页面收紧尺寸后，当前共用基准为：侧栏 232px、顶栏 64px、正文内容上限 1360px、标题 28–30px、常规按钮 38–40px、资料面板上限 1120px、资料表单上限 820px。CSS 高度不超过 900px 的窗口使用进一步紧凑的借出流程布局。Chrome 保持 100%，不使用整页 zoom。

配色和图片继续以交付包为视觉方向，导航使用深蓝底和蓝色选中态。真实数据和无封面状态保留。尺寸与完整 1:1 对照是两个记录范围，详见根目录 `design-qa.md` 和 `design/DESKTOP_VISUAL_REFINEMENT.md`。
