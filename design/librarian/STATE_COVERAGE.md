## 提交反馈复用

[资料保存中](profile/states/save-pending.png)、[成功](profile/states/save-success.png)、[失败](profile/states/save-failed.png) 是反馈组件的视觉样本。其他页面只复用按钮加载、成功提示、错误条的样式，保留各自表单、结果区和业务动作，不复制整张资料页面。

| 页面 | 请求中 | 成功 | 失败与恢复 |
| --- | --- | --- | --- |
| 分类 | 编辑弹窗原保存按钮加载 | 关闭弹窗，提示“分类已保存”，刷新列表 | 错误条及接口字段错误，保留弹窗与输入；名称最多 80 字、编码 2–32 位字母数字下划线或连字符、排序不小于 0 |
| 公告草稿 | 原保存草稿按钮加载 | 关闭编辑弹窗，“草稿已保存”，刷新 | 保留编辑与输入，显示全局或字段错误；标题 1–120 字、正文必填且最多 10000 字 |
| 公告发布／撤下 | 对应动作加载 | “公告状态已更新”，刷新；发布前的预览不自动关闭 | 错误提示，409／422 重新加载；发布先预览后确认，撤下直接确认 |
| 新增／编辑书目 | 原保存按钮加载 | “书目已创建”／“书目已更新”，进入该书副本页 | 保留表单；ISBN 冲突使用专用图，不增加覆盖或合并动作 |
| 封面上传 | 上传按钮加载 | “封面上传完成”，替换预览 | 原封面保留；类型和大小限制见封面状态板 |
| 书目启停 | 仅对应行的动作加载 | “状态已更新”，刷新 | 错误提示；409／422 重新加载 |
| 新增／修改副本 | 原操作按钮或对应行加载 | “副本已添加”仅清空条码；修改为“副本已更新”，刷新 | 错误提示，409／422 重新加载；冲突用“副本已被其他操作修改，请刷新” |
| 借出／归还 | 原办理按钮加载 | 分别使用已保存成功结果图；提示“借出办理完成”／“归还办理完成” | 保留输入，错误条；409／422 重新核验。归还已处理用“该借阅已处理，请重新核对条码” |
| 取消预约 | 原因校验通过并关闭输入弹窗后，对应行加载 | “预约已取消”，刷新 | 错误提示；409／422 刷新。网络失败保留幂等请求键，同一预约与原因重试复用；不能据设计图声称失败后输入弹窗仍打开 |
| 资料 | 保存资料按钮加载 | “资料已更新”，使用接口返回资料更新当前账号 | 保留输入和错误条，不增加手机号前端格式规则 |

## 相同结构的业务分支

| 已有基准 | 复用分支与准确行为 |
| --- | --- |
| 分类必填校验 | blur 分别为“请输入分类名称／请输入分类编码”；直接空值提交为“分类名称和编码不能为空”。服务端字段错误贴回对应字段，保留全局错误条。 |
| 分类停用确认 | 编辑且关闭启用时显示“确认停用”；取消只返回编辑，不发送保存。 |
| 书目停用确认 | 重新上架仅替换正文“确认重新上架《三体》？”，背景维持原状态直至成功。 |
| 副本维修确认 | 恢复可借和退役替换条码、目标状态；READY／BORROWED 不能直接改状态，RETIRED 禁用位置操作。 |
| 副本条码校验 | 无条码或超过 50 条：“每次请输入 1–50 个条码，每行一个”；位置为空：“请输入馆藏位置”；其余接口错误沿用全局错误条。 |
| 借出受限 | 按账号禁用、读者逾期、副本留给其他读者、副本不可借的优先级替换警告和核验内容；不能操作时禁用办理按钮。数量上限由接口反馈。 |
| 归还成功 | 当前图为“已恢复可借”；若返回 READY，仅替换为“已分配给下一位待取读者”，不展示下一位身份。 |
| 借阅主版与逾期筛选 | 已归还筛选复用主版中的已归还标签及操作短横线；逾期为在借记录的筛选。筛选后同步总数和分页。 |
| 预约主版、待取与排队筛选 | 已履约／已取消／已过期复用历史行的无操作样式；按 allowedActions.canCancel 决定是否允许取消，不能仅由状态推断。 |
| 密码错误结构 | 当前密码必填“请输入当前密码”；新密码 8–64 位；确认密码必填“请确认新密码”。必填、长度和一致性复用字段错误样式，不新增规则。 |

## 加载、空结果和请求失败

[加载](shared/list-loading.png)、[空结果](shared/list-empty.png)、[失败](shared/list-failed.png) 为列表内容区的视觉基准。筛选条、标题、导航留在各页面原位置；加载、错误、空数据和正常内容互斥，不同时叠加。现有 `LoadState.vue` 使用四行骨架、空数据区、标题“加载失败”和“重新加载”按钮；接线应遵循实际组件文案和重试回调。

| 容器 | 适配方式 |
| --- | --- |
| 分类、公告、借阅、预约、副本列表 | 保留本页筛选和新增／办理入口，状态替换列表区域；空结果总数为 0，清除过期行数据与可操作入口。 |
| 书目卡片与公开目录 | 同样的三种状态放进目录内容容器，保留搜索和筛选；失败重试当前条件，不呈现过期卡片。 |
| 编辑页、资料、详情等首次请求 | 骨架、错误和重试放在该表单或详情内容区；加载失败不伪造可提交数据。提交失败使用表内错误，保留已输入内容。 |
| 工作台与统计 | 请求失败复用错误组件。成功但无数据用 [统计空数据图](stats/states/empty-data.png)：指标为 0 且单位保留，分别“暂无趋势数据”“暂无热门书目”，不把 0 当请求失败。 |
| 公开公告与异常页 | 公告列表、详情适用相同请求组件；403／404 是独立路由结果页，按公共页说明复用。 |

不增加罚款、续借、催还短信、打印、人工分配副本或管理员专属功能。馆员设计的本轮生成完成不代表三个角色的全部设计已经完成或已获用户确认；三端及必要状态选择完成后才进入应用实现。
