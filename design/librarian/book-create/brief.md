# 馆员新增书目页面设计简报

2026-10-20 · 馆员端 `/staff/books/new` · 三个独立图片方案。

## 目标与来源

录入书目信息、选择封面和上架状态，保存后进入实体副本管理。已核对 `frontend/src/views/BookFormView.vue`、`BookInput` 和后端 `CatalogController.BookInput`。参考原有测试截图用于功能核对，不代表本轮运行前端。视觉沿用 [馆员图书管理定稿](../books/final.png) 与 [管理员新增书目定稿](../../book-create/final.png)。

## 共同字段与初始状态

- 必填：书名（1–200 字）、作者（1–120 字）、分类。仅这三个字段有必填星号。
- 可选：ISBN-13、出版社、出版日期、关键词、内容简介、封面。
- 所有文本字段为空，分类未选、日期未填、封面未上传；上架状态默认开启，旁有「上架」文字。
- ISBN 可留空，填写时校验有效 ISBN-13；关键词逗号分隔；简介最大 5000 字。
- 封面通过文件选择上传，JPEG、PNG、WebP，最大 2 MiB。不虚构拖拽上传、自动取封面或 ISBN 抓取能力。
- 主要按钮为「保存并添加副本」，对应现有保存书目后跳转副本管理的流程。辅助按钮「返回列表」。不增加保存草稿、下一步分步提交或保存并继续新建。
- 保存后的副本页面再维护册数、条码、馆藏位置。本表单不含这些字段、价格或评分。
- 无预填书名、书封、当前日期或校验报错；输入框中的浅色引导文案为占位符。

## 视觉与权限

深蓝侧栏、白色顶栏、浅蓝灰画布、白色圆角卡片、蓝色主要动作，中文无衬线字体。顶栏「欢迎回来，馆员」与「馆」头像；图书管理展开，仅「新增书目」子项选中，书目列表未选中。借阅管理收起，其余导航沿用馆员端。无账号管理或审计日志。

## 三个方向

1. 编目与封面双栏：左侧基本信息与简介，右侧封面上传和上架设置，底部保存操作。
2. 连贯分区表单：单一宽卡片内分基本信息、出版信息、展示与上架，紧凑双列字段与明确底部操作。
3. 封面引导工作台：左侧封面与上架面板，右侧书目字段与简介，顶部只读提示「录入书目 → 添加副本」，不把表单拆成未实现的向导。

三图内容、字段、初始状态相同，只改变空间组织与信息层级。目标画幅 1440 × 1024，全字段和主按钮完整可见，分别保存提示词和 PNG、检查后等待用户选择。全部三端图片完成并经选择前不生成应用代码。
