# 图书管理系统 · 全站视觉与布局规范

## 参考图判断

- 图 2 是比例与氛围基准：约 252px 深蓝侧栏、60px 浅色顶栏、浅冷色画布、紧凑白色内容卡。它展示的是一种页面结构，不代表图中的统计数字或公告可以作为真实数据使用。
- 图 1 的书目页中，标题、留白、输入框、表格行与操作都偏大；侧栏发生了不必要的滚动，且 20 条记录把整页拉长。
- 图 3 的公告仅一条，卡片却被与借阅表格对齐的栅格行撑高；应让公告卡片按内容收缩，并把借阅表格放进有上限的内部滚动区。

## 设计令牌

| 用途 | 色值 / 规则 |
| --- | --- |
| 侧栏 | `#142747` 至 `#1a3156`，选中态 `#2c70d6` |
| 画布 | `#f3f7fc`，顶栏与卡片 `#fff` |
| 主文字 / 次文字 | `#152747` / `#70809c` |
| 边线 / 阴影 | `#e7edf6` / 轻微蓝灰阴影 |
| 操作蓝 | `#2775ea`：主按钮、链接、焦点 |
| 成功青绿 | `#159f85`：可借、已归还、已完成 |
| 辅助紫 | `#7659c9`：预约与辅助信息 |
| 提醒橙 | `#d98a22`：待取、待处理 |
| 风险红 | `#d94b5f`：逾期、停用、失败 |

桌面侧栏宽 244–252px、顶栏高 60px、内容边距 16–20px；页面标题 23–25px，正文 13–14px，表格行约 40–44px，标准按钮高 32px。卡片圆角 12–14px，卡片之间 12–14px。仅首页主视觉可使用柔和渐变，其余以白卡与小面积语义色为主。

## 页面布局

| 页面族 | 桌面布局与信息层级 |
| --- | --- |
| 访客、读者首页 | 横向浅色主视觉、馆藏搜索，下方新到馆藏卡片网格和按内容收缩的公告列表。 |
| 图书目录、详情 | 目录使用紧凑筛选栏与封面卡片网格；详情用封面、书目信息和预约操作的双栏，简介在内容区滚动。 |
| 公告、我的借阅、我的预约 | 公告采用时间线式列表；借阅用状态筛选和紧凑表格；预约用带紫色状态提示的记录卡。 |
| 个人资料、密码 | 窄宽度表单卡，账号只读信息与可编辑字段分层。 |
| 书目、副本、分类 | 书目和副本使用紧凑工具栏、内部滚动表格和固定可见的分页；分类使用轻量清单及弹窗。 |
| 借出、归还 | 操作步骤卡：查人／查副本／核对提交。结果和异常直接显示在步骤附近。 |
| 借阅、预约、公告、账号、审计 | 状态或条件筛选 + 记录表格；公告编辑和账号编辑仍通过已有弹窗，保留全部校验与权限。 |
| 统计、管理员概览 | 真实指标小卡 + 图表；概览底部借阅记录与公告各自按内容高度排布，公告不足时自然收缩。 |

## 密度与状态

- 1366×768 与 1920×1080 均以浏览器视口为边界；主内容区可独立滚动，表格或卡片结果区设置内部滚动上限，分页不被长记录推走。
- 记录列表每页 10 条，目录每页 9 张卡片；大量数据依赖既有服务端分页。文字可换行或省略并提供可查看的完整内容，不能裁切操作按钮。
- 加载用骨架，空数据用明确空状态，接口错误保留重试，状态同时显示文字和语义色。危险操作使用红色文字和现有确认流程。
- 所有数字、书名、公告、借阅记录与权限均来自现有接口；样式调整不改变业务含义。
