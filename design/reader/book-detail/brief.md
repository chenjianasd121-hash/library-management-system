## 任务与依据

查看图书元数据、馆藏副本状态和内容简介，符合资格时办理预约，或进入我的预约查看结果。依据 `BookDetailView.vue`、`BookDetail`、预约 API 和当前 Chrome 测试数据；沿用读者首页第三张与图书目录第一张定稿。

三个方案均为同一本书已载入的普通详情状态：Java编程思想，Bruce Eckel，计算机类，ISBN 9787115546081，机械工业出版社，出版日期 2020-01-01，关键词 Java,编程，简介「系统介绍 Java 编程语言及面向对象思想。」。

馆藏数量为总册 8、可借 3、待取 1、借出 4，合计一致。数据来自旧测试样例，仅为设计演示，不代表当前数据库或该书的真实出版资料。封面沿用已选目录中的真实风格生成素材。

画面中的读者具备预约资格：没有逾期、本书的在借记录或有效预约；书目上架，预约信息加载成功。主按钮启用，写为「预约待取」，不展示成功、正在预约或权限受限提示。

## 功能边界

- 侧栏只有首页概览、图书目录（高亮）、系统公告、我的借阅、我的预约、个人中心；顶栏身份为读者张三。
- 标题为图书详情，辅助导航为返回目录。主动作「预约待取」，辅助「查看我的预约」。预约成功后可在我的预约查看取书信息。
- 保留 ISBN、出版社、出版日期、关键词、内容简介和四种馆藏数量，避免重复展示同一数据。
- 不增加直接借出、电子阅读、评分、收藏、推荐书单、购书价格、取书日期选择、条码或副本选择、管理编辑与删除。
- 初始详情不显示分配的副本条码、取书截止日期或排队序号，这些在预约后由服务返回。
- 不虚构取书天数、借阅次数和热门度；出版日期保留测试数据的旧日期。

## 三个方向

- 封面信息详情：一个宽白色书目表面，左封面、右元数据与数量，简介和操作自然接续。
- 预约侧栏详情：左侧阅读书目与简介，右侧独立预约区集中显示馆藏数量和主动作。
- 横向分区详情：上部横向封面与书目信息，下部元数据与简介，底部一条明确的预约操作区。

目标桌面 1440 × 1024，正文约 14–16 px，页标题约 28 px。三张均展示完整信息及操作，独立生成并保存图片和提示词，等待用户挑选。全部三个端图片确定前不生成代码。
