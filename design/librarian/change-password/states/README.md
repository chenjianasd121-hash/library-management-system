# 修改密码必要状态

沿用已选第三张主页面，所有密码保持遮罩。固定状态均待用户审阅。

- [当前密码错误](current-password-incorrect.png)：服务端 `PASSWORD_INCORRECT` 以顶部“当前密码不正确”呈现，不凭空添加字段错误。
- [两次密码不一致](password-mismatch.png)：顶部与确认密码字段同步提示，两次输入保留。字段同步提示是待审视觉细化，现有提交分支使用全局提示，尚未修改实现。
- 当前密码必填；新密码 8–64 位；确认密码必填且须一致。长度与必填复用同一字段错误结构，文案分别为“请输入当前密码”“新密码需为8–64位”“请确认新密码”。不额外要求字符组合。
- [首次登录强制改密](first-login-required.png)已保存；提交中／成功／失败适配见 [状态覆盖与复用](../../STATE_COVERAGE.md)。
- 成功清空三项密码、刷新会话；优先返回通过安全校验的原目标地址，否则进入馆员首页。失败保留输入，共享反馈不改变该导航规则。
