## 目标与依据

编辑已载入书目的信息、封面和上架状态。依据本会话已核对的 `BookFormView.vue`、`BookInput` 与 `frontend/tests/chrome-acceptance.mjs` 演示字段。视觉沿用 [馆员新增书目定稿](../book-create/final.png) 和 [馆员图书管理定稿](../books/final.png)。保存修改后沿现有代码进入该书目的副本管理，因此按钮「保存修改」旁提示「保存后进入副本管理」。

## 统一演示状态

三图使用同一已载入、尚未修改的演示书目：书名 Java编程思想，作者 Bruce Eckel，ISBN-13 9787115546081，分类计算机类，出版社机械工业出版社，出版日期 2020-01-01，关键词 Java,编程，简介「系统介绍 Java 编程语言及面向对象思想。」（22 字符）。书名计数 8 / 200，简介 22 / 5000。以上为演示数据，不代表本次读取数据库。

上架开关为开启。封面在本轮使用馆员目录已展示的黑金树木／夜景演示插画，显示已有封面预览与「上传封面」入口，重新选择文件可替换封面。这是对现有 coverPath 分支的设计演示；旧测试数据 coverPath 为 null，并未据此声称数据库已有该文件。不同于管理员旧编辑稿的未上传状态，本轮三张统一为已有封面，以延续馆员目录图内内容。封面不是官方出版书封。

## 字段、行为与权限

- 仅书名、作者、分类必填；其余字段可选。书名 1–200 字，作者 1–120 字，ISBN 可留空、填写则校验 ISBN-13，简介最大 5000 字，关键词逗号分隔。
- 出版日期保持该书既有日期 2020-01-01，不填入今天日期。无加载、报错、成功或未保存改动提示。
- 文件选择上传封面，JPEG／PNG／WebP，最大 2 MiB；不加入拖放、删除封面、自动取封面或图像编辑。
- 主动作「保存修改」，辅助「返回列表」，保存后进入副本管理。不加入草稿、重置、撤销、删除、版本历史或双重保存按钮。
- 本页不编辑副本数量、条码、位置、价格、评分等；不使用新增后的流程步骤条。
- 馆员头像「馆」及欢迎文字；图书管理展开、书目列表选中，新增书目未选中。无管理员专属菜单。

## 三个方向

1. 连贯分区编辑：延续已选新增页的单张宽卡片与分区顺序，字段已回填，展示已有封面。
2. 封面领衔编辑：一张白色表面内部左侧封面与上架、右侧完整元数据表单，底部动作。
3. 信息卡片编辑台：上部两张并列信息卡片，基本信息在左、出版与封面设置在右，下部通栏简介及操作栏。

三图保持字段、内容、已载入状态一致，只改变组织布局。目标桌面 1440 × 1024，全字段与主动作可见；逐图保存提示词和 PNG，检查后等待用户选择。全部三端图片完成且经选择前不生成应用代码。
