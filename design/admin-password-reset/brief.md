# 管理员重置密码弹窗

2026-10-21，Asia/Shanghai。仅管理员端，每页三张独立候选图后由用户选择。全部页面和状态确认前不生成应用实现代码。

功能依据：frontend/src/views/UsersView.vue 的 reset(u) 打开一个密码输入框，提示“为 {username} 设置一次性新密码（8–64 位）。”，8–64 位验证；backend/src/main/java/com/library/management/user/service/UserService.java 的 resetPassword 设置 mustChangePassword，前端成功提示“密码已重置，用户下次登录须改密”。本轮仅设计尚未填写的正常初始状态。

目标示例 librarian_01（陈晓），使用 design/admin-users/final.png 为背景。单个空密码框，不添加确认密码、旧密码、用户选择、角色选择、自动生成、短信、邮箱或发送功能。文案“用户下次登录须修改密码。”是行为说明，不是成功通知。按钮本轮中文设计统一为“取消”“确定”；保持蓝色主要操作和小型黄色警示图标，不画错误或成功状态。

视觉继承：深蓝侧栏、白顶栏、浅蓝灰背景；只有侧栏“读者管理”激活，管理员身份；背景账号管理 23 个账号、当前页 10 行、当前管理员禁用不可用。前景一个白色弹窗与统一蓝灰遮罩。

三个方向均使用同一功能、同一数据和同一套可见文案：
1. 紧凑提示式：约 490px 宽，标准标题、警示说明行、顶部标签与整宽密码框、下方说明及右对齐按钮。
2. 横向对齐式：约 580px 宽，标题与说明后固定左标签、右侧单个密码框，帮助文字跟随右侧输入边缘对齐，页脚按钮右对齐。
3. 宽幅警示式：约 640px 宽，警示图标与标题同排，说明下方顶部标签和整宽密码框，底部说明与两按钮同排，更浅的纵向尺寸。

使用内置 Image Gen，每张单独调用，输出即保存并记录源路径、尺寸与 SHA256，不裁切、不拉伸。
