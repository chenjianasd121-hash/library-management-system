# 个人资料必要状态

沿用已选第三张主页面。固定状态均待用户审阅。

- [显示名校验](display-name-validation.png)：空值时顶部与字段提示“显示名需为 2–40 字”，保留可选手机号，不增加手机号格式限制。
- [保存中](save-pending.png)、[保存成功](save-success.png)、[保存失败](save-failed.png)已保存，沿用本页实际字段与“保存资料”按钮。保存中的输入灰态是待审视觉细化，现有代码仅按钮加载，尚未修改实现。
- 用户名、角色只读。失败保留输入；成功提示“资料已更新”，使用服务端返回资料更新当前账号信息。其他表单的适配规则见 [状态覆盖与复用](../../STATE_COVERAGE.md)。
