# 编辑书目页面设计简报

2026-10-08 · 管理员端 `/staff/books/:id/edit` · 三个独立方案供挑选。

## 任务与依据

修改既有书目的基本信息、可选封面和上架状态。依据 `frontend/src/views/BookFormView.vue`、`frontend/src/api/types.ts` 和既有编辑书目测试截图；延续图书管理及新增书目定稿的视觉风格。

与新增页的区别是所有既有字段已回填，主动作写为「保存修改」。现有保存逻辑在编辑成功后也进入该书目的实体副本管理，因此辅文明确「保存后进入副本管理」。本页不录入册数、实体条码和位置。

## 统一演示状态

使用旧有测试截图中的演示书目，不表示当前数据库数据：书名 Java编程思想，作者 Bruce Eckel，ISBN-13 9787115546081（校验有效），分类计算机类，出版社机械工业出版社，出版日期 2020-01-01，关键词 Java,编程，简介「系统介绍 Java 编程语言及面向对象思想。」（22 字符）。

三个方案均为已载入、尚未修改的普通编辑状态；上架开启，封面尚未上传，显示可选的上传入口。旧截图同样未展示已有封面。无需成功、加载、错误或未保存改动提示；不增加版本历史或对比审核功能。

## 字段与动作

- 必填：书名（1–200 字）、作者（1–120 字）、分类。
- 可选：ISBN-13、出版社、出版日期、关键词、内容简介、封面。
- ISBN 可留空，填写时校验；关键词使用逗号分隔，简介不超过 5000 字。
- 封面文件选择上传，支持 2 MiB 以内的 JPEG、PNG、WebP；不添加拖放、删除封面或摄像头控件。
- 上架开关有文字含义；主要动作「保存修改」，辅助「返回列表」。
- 不加入 ISBN 自动抓取、智能内容、草稿、重复保存、撤销、版本历史、价格、语言、版次及无依据的业务数据。
- 导航高亮图书管理／书目列表，不能高亮新增书目；编辑页不使用新增后的步骤条。

## 三个方向

- 双栏书目编辑：沿用新增书目定稿的左表单、右封面设置布局，减少新增与编辑的学习成本。
- 封面领衔编辑：一张白色表面内部左侧是封面和状态，右侧是元数据与简介，靠分隔线区分。
- 通栏分组编辑：横向两列表单，简介与封面展示顺序向下展开，使用整宽表面。
