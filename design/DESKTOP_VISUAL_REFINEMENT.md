# 全站桌面尺寸与布局校准

2026-10-22。用户指出所有页面内容偏大、偏宽后，对三个门户的共用布局、字体、控件及主要页面完成一轮修订。Chrome 保持 100%，页面没有使用整体 zoom/transform 缩放。原设计的图片、配色方向和业务功能继续保留；本轮按用户最新要求调整桌面显示密度，不能将原 PNG 全图像素相等当作这一轮的完成标准。

## 已生效的变化

| 项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 侧栏 | 常规宽 274px | 232px；导航文字和行距同步收紧 |
| 顶栏 | 76–82px | 64px |
| 页面标题 | 读者 46px、后台 38px 等 | 常规 30px，矮屏 28px |
| 读者副标题 | 24px | 15–16px |
| 常规按钮 | 读者 51px 等 | 38–40px，保留清晰点击区域 |
| 业务内容宽度 | 随浏览器一直铺满 | 内容容器最高 1360px，宽屏居中 |
| 个人资料 | 面板和输入跟随整屏拉宽 | 面板最高 1120px，表单最高 820px；标签宽 120px |
| 图书详情 | 大封面、大标题和较多留白 | 封面 180×244px，书名 28px，信息区和动作区收紧 |
| 借阅列表 | 行高 108px、文字/按钮偏大 | 行高 76px，辅助信息分层，日期提示只显示一次 |
| 登录与注册 | 表单标题、输入框、提交按钮偏大 | 表单宽度、标题、输入和间距统一收紧，恢复登录必填星号与居中箭头 |

同时修正原图对照中确认的布局偏差：管理员横幅恢复新增书目、办理借出、办理归还入口；侧栏改为更接近原图的深蓝并恢复子菜单选中底；读者首页服务入口恢复纵向排列。详情中出版日期与出版社按参考位置排列。矮屏下借出核验卡片进一步压缩，保留全部信息，确认借出按钮完整位于 1366×768 首屏内。

没有对图书记录、账号或后端业务规则做调整。缺少封面的书目继续展示真实的无封面状态，姓名、书名、数量和日期继续读取后端。

- 默认构建（含 `vue-tsc`）和 reader/librarian/admin 三端构建通过；ESLint、Oxlint 与格式检查通过；现有单测 5/5。
- 独立 QA 后端上真实后台 Chrome 业务/异常/管理共 19 组回归通过，包含资料保存、改密、借还、预约、禁用/重置和公告弹窗。
- 53 页三档共 159 张最新截图已更新，Chrome 100%、DPR 1。1366×768 的截图另按最终矮屏样式重拍；馆员借出使用真实查询匹配已核验状态，没有提交实际借出。
- 另外检查 CSS 视口 1706×780、DPR 1.5（截图像素宽 2559），以及 2560×1440、DPR 1，分别覆盖图书详情、我的借阅、个人中心。内容宽度、字号、表单宽度和首屏保存按钮均通过断言。该条件为模拟验证，不推断用户实际 Windows 缩放设置。
- 本轮构建仍有现存大 chunk 提示，没有构建错误。后端代码未变，无需重复压力测试。
